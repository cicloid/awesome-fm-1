# Awesome M-VAVE FM-1 [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of resources, tools, custom firmware and open source work around the M-VAVE (Cuvave) FM-1 pocket FM synthesizer.

The FM-1 is a battery-powered, six-operator FM synthesizer with 32 algorithms, 27 silicone keys, a colour TFT screen, built-in effects, an arpeggiator and a step sequencer. It speaks Yamaha DX7 SysEx, so decades of DX7 patches load straight into it. It is built around a JieLi AC791N (WL82) SoC and updates its firmware over USB-MIDI SysEx, which is why it has become one of the most hackable synths of 2026: the updater was reverse-engineered within weeks of launch and a family of open source firmwares now runs on it.

**Flashing unofficial firmware is at your own risk.** The flash has a single bank and the board has no debug header, so read the recovery section below before you install anything.

## Official

- [Product page](https://www.m-vave.com/product?id=fm-1) - Specs and feature overview. Also at [cuvave.com](http://www.cuvave.com/product?id=fm-1).
- [Downloads](https://www.m-vave.com/download) - M-UPGRADE updater for Windows and macOS, the latest `.fwsc` firmware (V16, October 2026), MIDI control reference and release notes.
- [Firmware V16](https://yms-file-store.oss-cn-hongkong.aliyuncs.com/software/firmware/FM-1.fwsc) - Current official firmware image (October 2026): eight voices, 20-note polyphony and 64-step patterns. M-VAVE replaces the file at this address with each release.
- [Firmware V15](https://github.com/m-vave/fm1_open/raw/b178ac43c25f010c60a878056fb5331fe693fd62/sdk/firmware/FM-1_015.fwsc) - The previous official image, kept in M-VAVE's FM1 Open repository. Custom firmwares expect you to be on V15 first.
- [MIDI control reference (EN)](https://yms-file-store.oss-cn-hongkong.aliyuncs.com/software/releaseNote/firmware/FM-1%20MIDI%20EN.docx) - Official CC map, effects on their own MIDI channel.
- [Release notes](https://yms-file-store.oss-cn-hongkong.aliyuncs.com/software/releaseNote/firmware/FM-1.txt) - Official changelog for every firmware version.
- [User manual (PDF)](https://m.media-amazon.com/images/I/A1WOydif9HL.pdf) - Multi-language printed manual. Also mirrored on [manuals.plus](https://manuals.plus/ae/1005012499001058).
- [FM1 Open](https://github.com/m-vave/fm1_open) - M-VAVE's own open firmware repository. V14 adds 8 tracks, 8 sample slots and 16 FX demos; releases carry the development kit, a binary device-engine SDK and a [browser workbench](https://open.m-vave.com/fm1-workbench). Most new firmwares build on it or on fm1-base. GPL-3.0 with the FM1 SDK linking exception.

## Custom firmware

All of these install over USB from Chrome or Edge in a couple of minutes, and M-VAVE's own updater takes you back to stock. Most of the open source ones descend from Felucca. Two directories keep track of the whole field: the [FM-1 Firmware Hub](https://thefirmwarehub.com/) installs any open source firmware in one click, and the [FM1 firmware directory](https://fm1-editor.com/firmware/) lists every firmware with its status, latest version and install links.

### Open source

- [Felucca](https://github.com/hugelton/Felucca) - Multi-engine synth firmware by Leo Kuroshita (Hügelton Instruments). Thirteen engines (6-op FM, VA, phase distortion, chiptune, sampler, granular, physical modelling, organ, drums), four tracks, 64-step sequencer, song mode, mod matrix, USB audio, [web installer](https://hugelton.github.io/Felucca/), [web editor](https://hugelton.github.io/Felucca/webapp/editor/) and [browser emulator](https://hugelton.github.io/Felucca/webapp/try/). The platform most other firmwares build on. GPL-3.0.
- [SLOOP](https://github.com/isod89/sloop-fm1) - Live four-track groovebox by 3dSam: three synths plus a drum machine, 37 drum kits, punch-in FX, layer system, song mode, web editor. Based on Felucca. GPL-3.0.
- [X0X](https://github.com/charlesvestal/fm1-x0x) - ReBirth-style groovebox by Charles Vestal: TR-909, TR-808, two TB-303s with TB-3PO acid generators and a breakbeat slicer, each with its own sequencer. Has a [browser emulator](https://charlesvestal.github.io/fm1-x0x/emu/) and [manual](https://charlesvestal.github.io/fm1-x0x/manual/). Felucca fork. GPL-3.0.
- [FoMni](https://github.com/charlesvestal/fm1-fomni) - Omnichord-style chord harp by Charles Vestal: strum the white keys, pick chords on the black ones, with rhythm patterns and auto bass. [Installer and browser emulator](https://charlesvestal.github.io/fm1-fomni/). GPL-3.0.
- [BB1 (Big Beat)](https://github.com/TexasRADIO/bb1-firmware) - Rhythm firmware by TexasRADIO: two drum machines (KIT A and KIT B, each with its own pattern) and Dillo, an Open303-derived acid bass, through three-head tape echo and spring reverb. A synthesised 808, and kits that contain samples of the LinnDrum, LM-1, DrumTraks, DMX, Drumulator, Simmons and Rhythm King drum machines; 67 songs and 21 eras at their own tempos, 205 ACID bass phrases, MIDI in, saved scenes, a [one-click installer](https://thebigbeat.app/fm1/install/), [browser emulator](https://thebigbeat.app/fm1/emulator/) and [guide](https://thebigbeat.app/fm1/guide/). Felucca-based. GPL-3.0.
- [sloopDX](https://github.com/zvenson/dxsloop) - SLOOP fork that replaces its engines with a single six-operator DX7 engine ported from Dexed, every voice parameter editable on the device, room for 256 voices and 128-step patterns. [Installer and editor](https://dx7.designburgapps.com/). GPL-3.0.
- [GHOULBOX](https://github.com/jasonpersinger/ghoulbox-fm1-dungeon-synth) - Dungeon synth firmware by Jason Persinger: cathedral reverb, worn-tape effect, hurdy-gurdy engine with drones, dark ambient presets and an old-RPG screen. Felucca fork. GPL-3.0.
- [ChoralRoot FM-1](https://github.com/Quixotic7/ChoralRootFM1) - Orchid-style chord instrument: one hand plays roots, the other shapes chords, with voicings, key modes, bass and a looper. ## Firmware update and recovery

Stock updates and every custom installer go over USB-MIDI SysEx. If a flash fails the device may not boot, and the only way back in without opening the case is the chip's mask-ROM USB download mode, which needs a small hardware dongle.

- [fm1-linux-update](https://github.com/fuleo/fm1-linux-update) - Update stock V14 to V15 from Linux with verification, since M-VAVE only ships Windows and macOS updaters. MIT.
- [fm1_flasher.py](https://github.com/aroum/fm1-custom-fw/blob/main/fm1_flasher.py) - Standalone CLI flasher and preset uploader from the fm1-custom-fw project.
- [fm1_ota.py](https://github.com/AL-255/FM-1-RE/blob/main/tools/fm1_ota.py) - Linux USB-MIDI update client from the FM-1-RE project, with offline protocol tests.
- [FM-1 Transporter](https://github.com/kurogedelic/FM-1-transporter) - Read and write the FM-1's flash from a Mac through a Seeed XIAO RP2040 wired to the USB data lines. Dumps the full flash in seconds and is the recovery path for a device that no longer starts. MIT.
- [USB_KEY dongle notes](https://github.com/ip2k/lunar-modulator/blob/main/docs/10-usb-key-dongle.md) - Lunar Modulator's write-up of the RP2040 dongle that forces the AC791N into download mode over USB-C.
- [MvaveFM1Unbricker](https://github.com/Quixotic7/MvaveFM1Unbricker) - Python script that restores a soft-bricked FM-1 (black screen, installers report "FM-1 not found") over a plain USB cable through jl-uboot-tool, with a verified full-flash backup first. MIT.
- [flipper-fm1-recovery](https://github.com/merthsoft/flipper-fm1-recovery) - Uses a Flipper Zero to put the FM-1 into ROM recovery mode, then backs up and restores the flash from a Windows PC. No RP2040 or wiring needed. Unlicense.
- [fm-static](https://seajaysec.github.io/fm-static/) - Web installer for FM-1s whose MIDI port shows up under another name, which makes the usual updaters report the device as missing. [Source](https://github.com/seajaysec/fm-static), GPL-3.0.
- [How to update the firmware](https://medium.com/@shelvindatt02/how-to-update-the-firmware-on-your-m-vave-fm-1-synthesizer-7bc4ea2c3bd5) - Plain walkthrough of the official M-UPGRADE process.
- [fwradar changelog](https://fwradar.com/p/m-vave-fm-1) - Version history with changelogs for V09 through V15.
- [M-Flasher](https://github.com/jvitkauskas/m-flasher) - Backs up, restores and installs firmware on the FM-1 and SMK-37 Pro/Elite through the chip's USB download mode, so it works on a broken unit. Also installs the open bootloader. Windows, macOS and Linux, with a command line.
- [fm1_rescue.py](https://thefirmwarehub.com/rescue/fm1_rescue.py) - The FM-1 Firmware Hub's Linux rescue script: sends the FM-1 to the AC791N's mask-ROM bootloader, checks the flash chip, chip key and package, then rewrites only the firmware area, reading every sector back. For units no USB-MIDI installer reaches any more. GPL-3.0.
- [Slipway](https://github.com/Discodave-Glitch/slipway) - Windows app that lists community FM-1 firmware, checks the file and installs it through Felucca's installer, always keeping stock V15 as the way back. Includes a rescue flow and a recovery guide for a black-screen FM-1. MIT.
- [FM1Kit](https://github.com/ocean/FM1Kit) - Swift package that installs `.fwsc` firmware over USB-MIDI from iOS and macOS and can finish a cut-off update. Not yet tested widely on real hardware. MIT.
- [FM-1 Transporter multiboard](https://github.com/Nicodesy06/FM1Trasmitter-for-pico) - Derived workspace of FM-1 Transporter and MvaveFM1Unbricker that adds board profiles for recovering a USB-silent FM-1 with other RP2040 boards, including a DollaTek guide. Italian tutorial; DollaTek path untested on real hardware.
- [m-bootloader](https://github.com/jvitkauskas/m-bootloader) - Clean-room open bootloader for the FM-1 and SMK-37 Pro/Elite that adds a download mode and a recovery menu on the keys, plus the flash loader M-Flasher uses. Release has .fwsc installers. MIT.
- [FM-1 Swap](https://github.com/HyruleanHero1988/FM-1-Swap) - Android app that installs community firmware over USB MIDI, with the official V15 bundled as the way back, backups, a phone-side preview and DX7 patch sending. Inspired by FM-SWITCH. APK in releases. MIT.
- [FM-SWITCH](https://github.com/ocean/FM-SWITCH) - iPhone, iPad and Mac app for swapping FM-1 firmware over USB, with a firmware list merged from the Firmware Hub and fm1-editor.com and the official V15 bundled. By the author of FM1Kit. No licence stated.

- [Harbor](https://github.com/markterm/harbor) - Android app that plays FM-1 firmwares unchanged on the fm1-emu emulator, with USB and Bluetooth MIDI. APK in releases. No licence stated.
- [FM-1 Pocket](https://github.com/Prado-Design/fm1-pocket) - Phone web app (add to home screen) running the official FM1 Open V14 firmware compiled to WebAssembly behind a custom faceplate, offline after first load. GPL-3.0-only with the FM1 SDK linking exception.

## Patches and sound banks

- [fm1-factory-presets](https://github.com/KingParamount/fm1-factory-presets) - The original 128 factory voices recovered as four DX7 bank dumps, since the onboard reset only restores imported data. Includes SysEx protocol notes, a provenance table tracing 126 voices to known DX7 libraries, and an FM synthesis tutorial PDF. CC BY-SA 4.0.
- [fm1-banks](https://github.com/mene311/fm1-banks) - 26 thematic 32-voice DX7 banks (832 patches) with provenance tracking and an [audio gallery](https://mene311.github.io/fm1-banks/).
- [This DX7 Cartridge Does Not Exist](https://www.thisdx7cartdoesnotexist.com/) - Neural-network-generated DX7 cartridges, fresh every reload. Loads straight into the FM-1. [Source](https://github.com/Nintorac/NeuralDX7).
- [Ambient & Dreams](https://natlifesounds.com/product/ambient-dreams-for-m-vave-fm-1-fm-synthesizers/) - Commercial soundbank by NatLife Sounds made for the FM-1.

## Hardware add-ons

- [fm1-sustain-footswitch](https://github.com/pfkellogg/fm1-sustain-footswitch) - Arduino board that turns a 3.5 mm sustain pedal into MIDI CC64 on the FM-1's TRS MIDI in, with schematics.
- [FM-1 Bonus Box](https://github.com/pfkellogg/fm1-bonus-box) - ESP32-S3 companion box: sustain pedal, rotary preset browser with a round TFT, WiFi soundbank manager, USB MIDI keyboard host and a sing-on-key trainer.
- [fm1-midi-voice-tuner](https://github.com/pfkellogg/fm1-midi-voice-tuner) - Passive TRS MIDI splitter with a mic input and OLED that tells a singer whether they are on the FM-1's note.
- [fm1buddy](https://github.com/konsumer/fm1buddy) - Cheap hardware helpers: a USB MIDI host box that lets USB controllers plug straight into the FM-1, and a firmware switcher with an SD card of `.fwsc` files and MIDI mapping. [Browser install guide](https://konsumer.github.io/fm1buddy/). GPL-3.0.
- [fm1-cartridge](https://github.com/andrerezemini/fm1-cartridge) - ESP32-S3 cartridge with its own LiPo that acts as USB host for a modified SLOOP: it renders Clipper, Melodee or Felucca and returns stereo audio over USB. Experimental bench prototype; the repo lists hardware checks still to do. GPL-3.0.

## Related M-VAVE projects

Not about the FM-1, but the same company, often the same chips and the same reverse-engineering crowd.

- [smk37-firmware-custom-mod](https://github.com/amalahama/smk37-firmware-custom-mod) - Custom firmware and flasher for the SMK-37 Pro keyboard, which shares the FM-1's DX7 engine.
- [smk-37-pro-docs](https://github.com/jonathaslacerda/smk-37-pro-docs) - Community documentation for the SMK-37 Pro.
- [mvave-chocolate-sysex](https://github.com/cbix/mvave-chocolate-sysex) and [OpenChocolate](https://github.com/majabojarska/OpenChocolate) - SysEx protocol and open web configurator for the Chocolate footswitches.
- [mvave-blackbox-reverse-engineering](https://github.com/jakino0/mvave-blackbox-reverse-engineering) and [mvave-blackbox-edit](https://github.com/jvsobrinho/mvave-blackbox-edit) - Protocol research and a Web Bluetooth editor for the BlackBox amp modeller.
- [Cuvave Looper Pro protocol](https://gist.github.com/michaelforney/d3a2790bb5f8cbcb1c931eabb50b5f20) - SysEx protocol notes for the Looper Pro.
- [Felucca SMK](https://github.com/ChanceTheMaker/felucca-smk) - Felucca ported to the SMK-37 Pro and Elite by Chance Roth, with a browser Studio and simulator. 0.9.27 Beta. GPL-3.0.
- [fm1-to-smk37](https://github.com/genkigenki/fm1-to-smk37) - Kit for migrating open FM-1 firmwares to the SMK-37 with a coding agent such as Claude Code, and for developing for both boards from one source. By genkigenki. [Website](https://genkigenki.github.io/smk37/kit.html). No license declared.
- [Makkuro37](https://github.com/genkigenki/Makkuro37) - Microtonal drone synth for the SMK-37 by genkigenki: eight drones, 96 presets in six themes, with a [web installer](https://genkigenki.github.io/smk37/) and [simulator](https://genkigenki.github.io/smk37/makkuro37-sim/). Board layer from SLOOP. GPL-3.0.
- [Vector37](https://github.com/genkigenki/Vector37) - Orbiting overtone synth for the SMK-37 Pro by genkigenki: four corners of overtone generators blended by a sun and moon on an orbit, with eight sounds. Installs with `tools/fm1_install.py`. GPL-3.0.
- [mvave-blackbox-linux](https://github.com/Bulrok/mvave-blackbox-linux) - Native Linux control, cab IR upload and the documented USB-MIDI SysEx protocol for the Blackbox pedal, plus a Wine patch for the vendor editor. GPL-3.0.
- [smc-mixer-linux](https://github.com/Bulrok/smc-mixer-linux) and [smc-bridge](https://github.com/dhtseany/smc-bridge) - Two Linux bridges for the SMC-Mixer: one exposes its BLE-MIDI as an ALSA sequencer port, the other maps it to jack_mixer. GPL-3.0.
- [mvave-irbox-tools](https://github.com/marco-jardim/mvave-irbox-tools) - Open-source editor and protocol docs for the IR Box cab simulator over USB-MIDI: backup and restore of 32 slots, IR upload, EQ and volume. MIT.
- [mk300-re](https://github.com/NanamiKite/mk300-re) - MK300 firmware unpacking tools, SysEx protocol tools and static-analysis notes. Chinese README, no flashable firmware yet.
- [smc-pad](https://github.com/spectalive/smc-pad) - Swift bridge that lights the SMC-PAD's pads from QLC+ feedback over Bluetooth, with the tools and notes that mapped its LED protocol. Apache-2.0.
- [cubebaby-editor](https://github.com/walbertfreitas/cubebaby-editor) - Native Linux editor for the Cube Baby AC pedal: presets, IR import and audio interface use without Windows or Wine. English and Portuguese READMEs. MIT.
- [mvave-tank-mini-protocol](https://github.com/xxyurirangelxx/mvave-tank-mini-protocol) - Reverse-engineered BLE and USB-MIDI protocol specification for the Tank Mini pedal by Yuri Rangel. Portuguese README.
- [zoom-ms-chocolate-midi](https://github.com/nilsjesper/zoom-ms-chocolate-midi) - Generates a CubeSuite preset so a Chocolate Plus footswitch controls a Zoom MS-50G, with SysEx notes. MIT.
- [mvave-blackbox-nam](https://github.com/tomanizer/mvave-blackbox-nam) - Research towards running Neural Amp Modeler on the Blackbox pedal. Early, research baseline with no firmware built yet. MIT.
- [SMK37 OPEN](https://github.com/m-vave/smk37_open) - M-VAVE's official open firmware, web workbench and binary SDK for the SMK-37 Pro and Elite. GPL-3.0 with the SDK linking exception.
- [SLOOP Pro](https://github.com/isod89/sloop-pro) - The SLOOP groovebox on the SMK-37 Pro, Elite and MKE, by isod89 with a board layer by genkigenki, with an HTML editor in each release. GPL-3.0.
- [jellybean-37](https://github.com/edco/jellybean-37) - Open dual-engine firmware for the SMK-37 Pro (Juno-60-style VA plus DX7) with a host simulator and RAM loader. No licence stated.
